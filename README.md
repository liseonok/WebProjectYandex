City Oddities — это сайт, где пользователи могут добавлять на карту необычные и странные места города.

## Например:
- странные памятники
- необычные здания
- заброшенные места
- красивые, но малоизвестные места
- интересные дворы или объекты

Установка:
```bash
git clone https://github.com/liseonok/WebProjectYandex.git
cd WebProjectYandex
python -m venv venv
venv\Scripts\activate  # для Windows
pip install -r requirements.txt
python app.py
