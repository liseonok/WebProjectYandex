City Oddities — это сайт, где пользователи могут добавлять на карту необычные и странные места города.

## Например:
- странные памятники
- необычные здания
- заброшенные места
- красивые, но малоизвестные места
- интересные дворы или объекты


## Основной функционал:
1. Регистрация и вход
2. Главная страница:
- Название
- Карта
- Метки мест
- Кнопка "Добавить место"
3. Просмотр описания места по нажатии на метку
4. Страница места
5. Добавление своего места, если пользователь авторизован
6. Профиль пользователя:
- Информация о пользователе
- Список добавленных мест, их удаление и редакция

### Страницы проекта
1. Главная страница с картой  
2. Страница регистрации  
3. Страница входа  
4. Страница одного места  
5. Страница профиля 

## Что должно быть реализовано
- регистрация и авторизация;
- база данных;
- работа с ORM-моделями;
- карта с метками;
- просмотр описания мест;
- добавление нового места;
- удаление своих мест;
- загрузка фотографии;
- профиль пользователя.
