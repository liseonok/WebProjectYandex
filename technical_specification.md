## Основной функционал:
1. Регистрация и вход
2. Главная страница:
- Название
- Карта
- Метки мест
- Кнопка "Добавить место"
3. Просмотр описания места по нажатии на метку
4. Страница места
5. Добавление своего места, если пользователь авторизован
6. Профиль пользователя:
- Информация о пользователе
- Список добавленных мест, их удаление и редакция


### Страницы проекта
1. Главная страница с картой  
2. Страница регистрации  
3. Страница входа  
4. Страница одного места  
5. Страница профиля 

## Что должно быть реализовано
- регистрация и авторизация;
- база данных;
- работа с ORM-моделями;
- карта с метками;
- просмотр описания мест;
- добавление нового места;
- удаление своих мест;
- загрузка фотографии;
- профиль пользователя.

## Структура базы данных:
1. Пользователь
2. Отмеченное место
3. В месте хранится название файла картинки, картинка находится в папке static/images
